# Python Course (FastAPI + React)

Онлайн-платформа для изучения программирования по образцу Stepik и LeetCode. Пользователи проходят курсы, состоящие из модулей и уроков, решают практические задачи прямо в браузере, получают подсказки, зарабатывают звёзды и соревнуются в рейтинге. Код решений проверяется через Judge0.

Проект выполнен как дипломная работа: бэкенд на FastAPI и полноценный фронтенд на React.

## Описание

Платформа позволяет:

- регистрироваться и входить в аккаунт,
- проходить курсы, разбитые на модули и уроки,
- решать задачи по программированию с автоматической проверкой кода,
- использовать подсказки к задачам,
- оставлять комментарии к урокам и задачам,
- отслеживать свой прогресс по курсам,
- зарабатывать звёзды за решённые задачи и тратить их в магазине,
- смотреть рейтинг пользователей,
- управлять профилем

Дополнительные особенности:

- **Проверка кода через Judge0**: решения пользователей выполняются в изолированной песочнице, а результаты возвращаются в интерфейс 
- **Система звёзд и платежей**: внутренняя валюта, пакеты звёзд и магазин
- **Авторизация на JWT с refresh-токенами**
- **Ролевая модель** USER / TEACHER / ADMIN 
- **Многоуровневая структура контента**: курс → модуль → урок → задача
- **Тёмная тема** и собственный дизайн интерфейса без UI-фреймворков (CSS Modules)

## Архитектура

Бэкенд построен слоями: роутеры принимают запросы, CRUD-слой работает с базой, Pydantic-схемы описывают данные на входе и выходе.

```
React (Vite)  ──HTTP──>  FastAPI (routers)  ──>  CRUD  ──>  База данных
                               │
                               └──> Judge0 (проверка кода)
```

Разделение по слоям:

- `api/routers` — HTTP-эндпоинты, по одному роутеру на сущность (курсы, модули, уроки, задачи, подсказки, комментарии, платежи, звёзды, профиль, регистрация и вход)
- `api/crud` — функции работы с базой для каждой сущности и логика прогресса, звёзд и платежей
- `api/dependencies.py` — зависимости FastAPI (текущий пользователь, проверка ролей)
- `core/models` — SQLAlchemy-модели
- `core/shemas` — Pydantic-схемы запросов и ответов
- `core/auth.py` — работа с JWT и паролями
- `core/config.py` — настройки приложения
- `migration` — миграции Alembic

## Развёртка

Перед началом использования необходимо клонировать репозиторий. Используйте команду в терминале:

```bash
git clone https://github.com/noskovde2015-byte/python-course.git
```

После этого перейдите в папку проекта:

```bash
cd python-course
```

Что понадобится заранее:

- Python и [Poetry](https://python-poetry.org/)
- Node.js и npm
- PostgreSQL


### Бэкенд

1. Установить зависимости (из корня проекта):

```bash
poetry install
```

2. Создать файл `.env` в папке `backend` (переменные перечислены ниже).

3. Применить миграции:

```bash
cd backend
poetry run alembic upgrade head
```

4. Запустить сервер:

```bash
poetry run uvicorn main:app --reload
```

Документация API будет доступна по адресу:

http://localhost:8000/docs

### Фронтенд

В новом терминале:

```bash
cd kzn-dev-frontend
npm install
npm run dev
```

Приложение откроется по адресу:

http://localhost:5173

### Переменные окружения

Пример файла `backend/.env`:

```env
# База данных
APP_CONFIG__DB__URL==your_database_url

# Авторизация (JWT)
APP_CONFIG__AUTH__SECRET_KEY=change_this_to_a_long_random_string
APP_CONFIG__AUTH__ALGORITHM=HS256
APP_CONFIG__AUTH__ACCESS_TOKEN_EXPIRE=30
APP_CONFIG__AUTH__REFRESH_TOKEN_EXPIRE=7
```



Секретный ключ можно сгенерировать командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## Технологии

Проект написан с использованием:

**Бэкенд**

- **Python** — основной язык
- **FastAPI** — фреймворк для API
- **SQLAlchemy** — ORM для работы с базой
- **Alembic** — миграции схемы
- **Pydantic** — валидация данных и схемы запросов/ответов
- **JWT** — авторизация с access- и refresh-токенами
- **Judge0** — проверка кода пользователей
- **Poetry** — управление зависимостями

**Фронтенд**

- **React** — интерфейс
- **Vite** — сборка и dev-сервер
- **CSS Modules** — изолированные стили
- **ESLint** — проверка кода

## Возможности API

Полный список эндпоинтов со схемами запросов и ответов доступен в Swagger UI (`/docs`) после запуска бэкенда. Основные группы:

| Группа | Описание |
|--------|----------|
| Регистрация и вход | Создание аккаунта, получение и обновление токенов |
| Курсы, модули, уроки | Структура учебного контента |
| Задачи и подсказки | Условия, тесты, подсказки, отправка решений |
| Комментарии | Обсуждение уроков и задач |
| Прогресс | Отслеживание пройденного материала |
| Звёзды и платежи | Баланс, пакеты звёзд, покупки |
| Профиль и пользователи | Данные пользователя, управление пользователями |
